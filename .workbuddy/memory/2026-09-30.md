### 关键设计决定

- 默认色块从 9 个改为 6 个：拨打电话 / 通讯录 / 抖音 / 微信 + 「常用工具」(手电筒·无线网·移动流量)

  「首次运行 → 返回默认」和「用户全删了 → 返回空列表」。
- 自适应列数 `columnsFor()`：0/1→1 列，2→2 列，4→2 列（2×2 块更大），其余 3 列；
  格宽 = (屏宽-16dp)/列数，高度上限 180dp，避免只有 1 个色块时撑满整屏。
- 星期：`TextClock` 的 `EEEE` 跟随系统 locale（英文机就是英文），改为 `TextView tvDate` +

- 色块有二级菜单时右上角显示「▾」标记（`item_home_button.xml` 根改成 FrameLayout 才放得下）。

### 踩坑记录（重要）

- **弹窗里不要持有 list 元素引用后再重新反序列化**。最初的 `saveBlocks()` 会 `loadBlocks()` 重新

  必须显式覆盖 `layoutParams`，否则在 wrap_content 容器里会量不出来。

## 第二版：精简顶部 + 文字跑马灯 + 突破 9 个上限（「更多」格）

需求：顶部不要「下午好」只留时间/日期/周几；色块文字显示不全要左右滚动（放得下不滚）；
超过 9 个程序时右下角改成「更多」，用二级菜单的大图标列出其余应用。

### 改动

- **顶部**：删除 `activity_main.xml` 的 `tvWeather`，`MainActivity` 删掉 `updateGreeting()`（含
  `onCreate` / `onResume` / `ACTION_TIME_TICK` 三处调用）。「下午」只来自问候语；`clockTime` 用的是
  `format12Hour="HH24"` 形式的 `HH:mm`，12 小时制机型也不会带上午/下午后缀。
  顺手删掉不再使用的 `hello` / `weather_unknown` 字符串。
- **文字滚动**：`item_home_button.xml` 的 label 改成 `maxLines=1 + singleLine + ellipsize="marquee"
  + marqueeRepeatLimit="marquee_forever"`，宽度 `match_parent`（原来是 `wrap_content + maxLines=2 + end`，
  文字宽于色块时直接被裁掉）。
  `BlockCell.bindLabel()` 在 `post{}` 里用 `label.paint.measureText(text)` 与可用宽度比较：
  放得下 → `gravity=CENTER` 且 `isSelected=false`（不动）；放不下 → `gravity=START|CENTER_VERTICAL`
  且 `isSelected=true`（跑马灯）。TextView 的 `setSelected(true)` 内部会走 `startMarquee()`，
  而 `canMarquee()` 本身会判断行宽是否超过控件宽度，所以「放得下就不滚」是双保险。
  注意 `gravity=CENTER + marquee` 会把文字两头都切掉，必须先切成左对齐。
  `post{}` 里要校验 `label.text` 是否已被复用改掉，避免 RecyclerView 复用导致状态错乱。
- **上限与「更多」**：`BlockCatalog` 新增 `MAX_GRID_SLOTS=9`、`VISIBLE_BLOCKS=8` 与
  `hasMore/homeVisible/homeHidden`；`MAX_BLOCKS` 9 → 30（只做防呆）。
  规则：色块 > 9 个时主页只摆前 8 个，第 9 格变成「更多」（右上角角标 `+N`，`ic_more.xml` 三点图标），
  点开复用二级菜单样式的大图标弹窗列出 `homeHidden()` 的结果，点其中一项直接执行
  （若该项自身有二级菜单，则继续弹它的二级菜单）。
- `HomeAdapter` 新增 `onMoreClick`，`submit()` 内部按 `homeVisible/homeHidden` 拆分，
  `getItemCount() = items.size + (hiddenCount > 0 ? 1 : 0)`；空列表仍显示「添加功能块」占位块。
- `BlockMenuDialog` 泛化为 `show(activity, title, items, hint, onPick)`；`dialog_block_menu.xml` 的
  `llSubContainer` 外包一层 `ScrollView(svSub)`，在代码里按行数算高度并上限为
  `屏高 - 260dp`，条目几十个也不会顶出屏幕。
- 管理页提示改为「已用 N 个色块，主页最多放 9 格，超出的收进「更多」」；
  `BlockRowAdapter` 对第 9 个及以后的条目在副标题追加「· 「更多」里」，让顺序一目了然。

## 第三版：应用多选改成「已选记忆 + 去重」，新增老人大键盘拨号页

需求：①「其他应用」多选里已添加的 APP 保持选中、避免重复添加；②拨号不跳系统拨号界面，自己做老人大键盘。

### 应用多选（`HomeBlocksActivity`）

- `pickApps()`：打开时用目标列表里已有的 APP 包名做**预置打勾**（`BooleanArray(apps.size) { apps[it].pkg in selected }`），
  并算出 `elsewhere = BlockCatalog.usedAppPkgs(blocks) - selected`，把「别处已有」的项在标签后加

- `addPickedApps()` 换成 `syncPickedApps()`：按包名做**差异同步**——保留勾选的（保持原顺序）、
  丢掉取消勾选的、追加新勾选的。同一包里出现重复的历史数据只保留第一个。
  `room = (limitFor(owner) - kept.size).coerceAtLeast(0)`，放不下时提示「只添加前 N 个」。
  变动为 0 时不落盘、只回到上一层，避免无意义写入。
- 新增 `BlockCatalog.usedAppPkgs()`（含二级菜单里的），`usedActions()`（内置功能去重）保持原样。

### 老人大键盘拨号（新增 `DialActivity` + `activity_dial.xml`）

  `weight=1`、`32sp` 粗体、白底 `bg_key` 圆角 18dp）→ 大号「删除/清空」（`DialActionKey`，64dp 高）→
  绿色「拨打电话」（80dp 高，`bg_call_btn`，色值 `btn_call = #FF07C160`）。
- 交互：按数字追加并 `TtsManager.speak` 语音播报该数字；删除键短按删一位、长按清空；空号时拨打键 alpha 0.5，
  点它提示「请先输入号码」。号码上限 20 位。
- 拨号：有 `CALL_PHONE` → `ActionExecutor.call()` 直接拨出并 `finish()`；无权限 → 先申请，

  常用联系人无权限兜底和拨号页兜底使用，没删。

## 第五版：新增微信视频号 + 修复真机「图标文字只显示上半部分」

需求：①能直接打开微信「视频号」；②真机上色块文字只显示上半截。

### 微信视频号（`HomeAction.CHANNELS`）

- 微信没有官方开放的视频号跳转，查证后 `weixin://channels` = 视频号首页（微信 7.0+，两个来源交叉确认）。
  `ActionExecutor.openChannels()` 依次尝试 `weixin://channels` → `weixin://dl/channels` → `weixin://channelslive`，
  都不可用则退回打开微信主界面 + toast「已打开微信，请在发现里点开视频号」。
- `HomeBlock.kt` 的 `HomeAction` 加 `CHANNELS`，`BlockCatalog` 的 `ORDER / ICONS / LABELS / COLORS` 四处同步补，
  `PALETTE` 也塞了新色；`MainActivity.onAction()` 加分支（TTS「视频号」+ openChannels）。
- 新资源：`drawable/ic_channels.xml`（白描边圆角框 + 播放三角，注意描边 path 要显式
  `fillColor="#00000000"` 否则会被填黑）、`color/btn_channels = #FFFA9D3B`、`string/act_channels`、
  `string/wx_channels_fallback`。
- **默认色块没动**（用户已有自定义布局，改默认值对他无感），视频号出现在
  管理页「添加功能块 → 内置功能」列表里（该列表由 `ORDER` 过滤 `usedActions` 生成）。

### 文字只显示上半截（真机）

- 根因：格子高度 = `min(cellWidth, 180dp)`，而 `cellWidth` 在窄屏 / 系统「显示大小·字体」调大时会变小，
  一旦小于「上下 padding 12dp×2 + 图标 56dp + margin 10dp + 一行文字」，居中的 `wrap_content` 容器就溢出，
  被 FrameLayout 裁掉 → 文字底部（有时连图标顶部）被切，看起来就是「只显示上半部分」。
- 修法（只改 `ui/BlockCell.kt` + 两处取高度的调用方）：
  1. 新增 `minBlockCellHeight(context)`：inflate 一个探针 `item_home_button`，用真实 label 的
     `paint.fontMetrics`（`bottom - top`，比实测行高更保守）+ padding + marginTop + 4dp 余量 + 图标基准高度。
  2. `HomeAdapter.submit()` 与 `BlockMenuDialog` 的 cellHeight 都 `coerceAtLeast(minBlockCellHeight(...))`
     —— 空间不够时**把格子加高**（主页在 NestedScrollView 里，可滚动），而不是裁字。
  3. `bindBlockCell` 里新增 `fitIcon()`：格子仍然偏矮时把图标高度压到
     `cellHeight - reservedHeight`，下限 26dp —— 文字优先级高于图标。
- 关键坑：压小图标时上限基准必须取 `getDimensionPixelSize(R.dimen.icon_normal)`，
  不能读 `icon.layoutParams.height`（RecyclerView 复用会把压小后的值当基准，越压越小）。
- 顺带的收益：二级菜单 / 「更多」弹窗（同一个 `item_home_button.xml`）也一起修好了。

## 第六版：视频号改成无障碍自动导航 + 色块排序 + 注册为手机桌面

需求：①点视频号打不开（真机验证 scheme 无效）；②功能块管理页要能调整顺序；③把 App 做成可注册的 launcher。

### 视频号：放弃 scheme，改用无障碍自动点

- 结论：`weixin://channels` 之类**在真机上无效**（微信自 6.6.7 起移除大量私有 scheme，
  视频号也从未进白名单），所以之前那版必然点了没反应。
- 改为无障碍自动导航（`ElderAccessibilityService`）：
  - 新增 `companion fun openChannels(ctx): Boolean`：先 `getLaunchIntentForPackage("com.tencent.mm")`
    把微信拉到前台，返回 `false` 表示无障碍没开（调用方走兜底）。
  - 实例内维护 `steps`（`mutableListOf<String>`）+ `stepIndex` 的**文案点击序列** `["发现", "视频号"]`，
    在 `onAccessibilityEvent` 里推进：只处理 `packageName == com.tencent.mm` 且
    `TYPE_WINDOW_STATE_CHANGED / TYPE_WINDOW_CONTENT_CHANGED` 的事件，两步之间至少隔 600ms，
    每步 12s 超时（超时 Toast `wx_channels_not_found` / `wx_channels_failed`）。
  - `clickByLabel()`：把所有窗口的 root（`rootInActiveWindow` + `windows[].root`）都找一遍，
    DFS 收集 `text` / `contentDescription` **精确匹配**的节点（没有再退化为「以目标开头且长度 ≤ +2」的宽松匹配），
    取最深的那个，`clickNode()` 先自己点、不行往上找最近的可点击父节点（最多 6 层），
    全都不行才用 `dispatchGesture` 按坐标点一下（`canPerformGestures=true` 已开）。
  - 找不到「发现」多半是微信停在聊天详情页 → `performGlobalAction(GLOBAL_ACTION_BACK)` 最多 3 次。
    **两个保险**：①`BACK_GUARD_MS = 1800` 内不按返回；②只有 `rootInActiveWindow.packageName == "com.tencent.mm"`
    时才按 —— 否则动画切换期间前台还是我们自己，会把微信直接退掉。
  - `accessibility_service_config.xml` 加了 `flagIncludeNotImportantViews`（微信部分 view 会被标记为不重要）。
  - 兜底链：无障碍没开 → 试 3 个 scheme → 都没有就打开微信首页 + toast。
- `MainActivity`：`HomeAction.CHANNELS` 分支里先判 `ElderAccessibilityService.isReady()`，
  没开就弹 `channels_need_accessibility` 对话框（去开启 / 只打开微信 / 取消）。

### 管理页调整顺序（`HomeBlocksActivity` + `BlockRowAdapter`）

- `item_home_block_row.xml` 右侧加 `btnMoveUp` / `btnMoveDown`（新 `ic_arrow_up/down.xml`，40dp 宽），
  第一行上移、最后一行下移按钮置灰 + `isEnabled=false`（新常量 `DISABLED_ALPHA = 0.25f`）。
- **`BlockRowAdapter` 必须持有外面传进来的同一个列表实例**（`private var items: List<HomeBlock>`
  + `submit(list) { items = list }`），否则拖动时改外层 list、`notifyItemMoved` 对不上 adapter 里的副本。
- `ItemTouchHelper.SimpleCallback(UP or DOWN, 0)` + `isLongPressDragEnabled = true` 支持长按整行拖动；
  `onMove` 里 `blocks.add(to, blocks.removeAt(from))` + `notifyItemMoved`；
  `clearView` 里**只 `persist()`**（落盘 + 刷 hint），再 `post { refresh() }` ——
  避免在 `clearView` 里直接 `notifyDataSetChanged`。
- `refresh()` 拆成 `persist()`（写盘 + hint）和 `refresh() = persist() + adapter.submit()`。
- `blocks_hint` 文案补一行「按住一行拖动可排序，也可以用 ↑ ↓ 微调」。

### 注册为手机桌面（Launcher）

- `AndroidManifest.xml`：`MainActivity` 加 `android:stateNotNeeded="true"`，
  并把 intent-filter 拆成两个 —— 一个 `MAIN + HOME + DEFAULT`（桌面），一个 `MAIN + LAUNCHER`（应用列表）。
- `MainActivity.setupBackBehavior()`：用 `onBackPressedDispatcher.addCallback`，
  **是默认桌面时吞掉返回键**（否则会闪一下黑屏再被系统拉起），不是默认桌面才放行默认逻辑

## 第八版：支持多个微信小程序 + 自定义命名

需求：原来设置里只能填一个小程序标识（`etWxMini` 单个输入框），改成可以添加多个、每个都能自定义名称。

### 数据层

- 新增 `util/WxMiniApp.kt`：`(id, name, target)` + JSON 读写 + `MAX_ITEMS = 20`。
  `target` 是小程序的「身份」，支持多种写法（见下）；`jsonToList` 会丢掉没有 target 的坏数据。
- `PrefsManager`：`getWxMiniProgram/setWxMiniProgram` 换成
  `getMiniApps(): MutableList<WxMiniApp>` / `setMiniApps(list)`，key = `wx_mini_apps`。
  **保留旧键 `wx_mini_program` 只做一次性迁移**：新键不存在且旧值非空时，把它变成列表里的第一项
  （名称用 `wx_mini_default_name`），老用户升级不会丢配置。
- `HomeBlock` 新增 `BlockType.MINI`（复用 `pkg` 字段存小程序标识/链接，序列化格式不用改），
  加 `isMini` 属性、`BlockCatalog.mini(label, target, color)`；
  `fromJson` 增加 `MINI && pkg.isEmpty() → null` 的校验。
- `BlockCatalog.usedAppPkgs()` 换成 **`usedKeys(blocks, type)`**（APP 与 MINI 各用各的键空间），
  原来的实现用 `!block.isBuiltin` 判断 APP，加了 MINI 之后会把小程序标识也当成包名。

### 打开小程序（`ActionExecutor.openMiniProgram`）

查证后（微信官方文档口径）三条路，按顺序判断：
1. `weixin://...` → 小程序后台生成的**明文 / 加密 Scheme**（明文格式
   `weixin://dl/business/?appid=APPID&path=PATH&env_version=release`，需在小程序后台
   「设置 → 隐私与安全 → 明文 Scheme 拉起此小程序」声明，非个人主体可用），原样打开最可靠；
2. `http(s)://...` → 小程序 **URL Link**（`https://wxaurl.cn/...`）或分享链接，交给系统打开；
3. 其余（`gh_` 原始 ID、`wx` AppID、`xxx@app`）→ 包装成 `weixin://dl/business/?username=...`
   （老写法，和旧版实现一致，保持兼容）。
都失败时 `openWeixinHome()` 打开微信首页 + toast `wx_mini_fallback`（带小程序名字）。
`openWeixinApp()` 已删除，改用 `openMiniProgram` / `openWeixinHome`。

### 设置子菜单（新增 `WxMiniActivity`）

- 入口：设置页原来那张含 `EditText` 的卡片换成可点行 `rowWxMini`（右侧显示「已添加 N 个」/「未添加」，
  `onResume` 刷新），点击进 `WxMiniActivity`。
- 列表 `ui/WxMiniRowAdapter.kt` + `item_wx_mini_row.xml`（微信绿圆形底 + `ic_wxapp` 图标、自定义名称、标识小字、
  ↑ ↓ ✕），拖动排序与色块/快捷拨号管理页同一套。
- 编辑弹窗 `dialog_edit_mini.xml`：名称 + 标识 + **粘贴按钮**（读剪贴板，方便粘分享链接）+
  说明文字。弹窗的 **Neutral 按钮是「试一试」**：不关弹窗，直接用当前填的内容
  `openMiniProgram()` 试一次，打不开可以立刻改，解决「不知道填什么才能打开」的问题。
- 同一标识加两遍会被拦住（toast `wx_mini_duplicate`）。

### 主页与色块管理页接入

- `MainActivity.onAction(WXAPP)` → `openMiniPrograms()`：0 个只开微信、1 个直接开、
  **多个则用 `BlockMenuDialog` 弹三列大图标列表让长辈挑**。
- `MainActivity.performBlock()` 按 `isBuiltin / isMini / else` 三分支；`BlockCell` 与 `BlockRowAdapter`
  对 MINI 统一用 `ic_wxapp`（小程序没有可用的应用图标，原来会去查包名导致显示成默认齿轮）。
- `HomeBlocksActivity`：「添加什么？」和「添加子功能」的选项从 2 个变 3 个
  （内置功能 / 其他应用 / **微信小程序**）。原来的 `pickApps` + `syncPickedApps` 泛化成
  **`pickItems` + `syncPickedItems`**（入参 `type` + `List<PickEntry>`，`PickEntry(key, label)`），
  APP 与 MINI 共用同一套「预置打勾 + 差异同步 + 已在别处标注 + 去重」逻辑；

  一个都没配小程序时弹框引导去「设置 → 微信小程序」（`blocks_no_mini` + 跳转按钮）。
