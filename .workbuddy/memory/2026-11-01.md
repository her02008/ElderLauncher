### 核查中发现的两个待决策问题（**都不是 bug，是设计缺口**）

1. **「恢复出厂设置」无法只清设置而保留管理员密码**，与 MK 原始需求（「恢复除管理员密码外的所有设置」）有偏差。
   根因：密码盐+哈希（`admin_salt`/`admin_hash`）与普通设置**同存于 `elder_prefs` 这一个 SharedPreferences**
   （`PrefsManager.kt:8` `PREFS = "elder_prefs"`；`AdminGate` 通过 `PrefsManager.getAdminSalt/Hash` 读写）。
   `PrefsManager.clearAll()` = `sp(ctx).edit().clear().commit()` → 连带清掉密码。
   `DialActivity.confirmResetEverything()` 当前顺序：`clearPassword()` → `clearAll()` → `QuickIconStore.clearAll()`，
   两条路（不勾 = 只清密码；勾 = 全清）之间没有「保留密码只清其他设置」这一档。
   → 修法二选一：① 把密码迁到独立 prefs 文件；② `clearAll` 改成白名单式保留密码键。等 MK 拍板。

2. **项目完全未纳入 Git**（`0930-ElderLauncher/` 下无 `.git`）。已迭代到构建 46，`.workbuddy/memory/MEMORY.md`
   的 196 行是唯一防坑知识库。建议 `git init` + 首次全量提交打 tag `v1.0.45`，之后每次构建前 commit。
